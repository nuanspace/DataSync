# 饮酒史字典模板

## 使用位置

接口映射工作台中，选中“饮酒史”字段后，在“详细设置”中配置：

```text
字典代码：drinking_history
字典匹配：按排序优先命中
```

然后点击“新建字典”或“编辑字典”，按下面顺序配置字典条目。顺序很重要，“按排序优先命中”只取第一条命中的目标选项。

## 推荐目标选项顺序

1. 从不饮酒
2. 偶尔饮酒（＜1次/月）
3. 经常饮酒（≥1次/月）
4. 偶尔饮酒
5. 仍在饮酒

## 字典条目模板

### 从不饮酒

| 命中条件 | 大概覆盖范围 |
| --- | --- |
| `从不饮酒` | 明确写“从不饮酒”。 |
| `否认饮酒` | 否认当前或既往饮酒。 |
| `否认酒精` | 否认酒精接触。 |
| `无饮酒史` | 明确写无饮酒史。 |
| `未饮酒` | 明确写未饮酒。 |
| `平素不饮酒` | 平素不饮酒。 |
| `不饮酒` | 普通“不饮酒”描述。若院内常用“目前不饮酒”表示已戒酒，建议不要配置这一条。 |
| `滴酒不沾` | 明确写滴酒不沾。 |

### 偶尔饮酒（＜1次/月）

| 命中条件 | 大概覆盖范围 |
| --- | --- |
| `偶尔饮酒` | 明确写偶尔饮酒。 |
| `偶饮` | 简写“偶饮”。 |
| `偶有饮酒` | 明确写偶有饮酒。 |
| `间断饮酒` | 间断饮酒。 |
| `少量饮酒` | 少量饮酒。 |
| `社交性饮酒` | 社交性饮酒。 |
| `regex:(?:饮酒|喝酒).{0,8}(?:小于|少于|低于|不到|不足|<|＜)\s*1\s*次\s*/?\s*(?:月|每月)` | 描述饮酒频率低于每月 1 次。 |
| `regex:(?:<|＜)\s*1\s*次\s*/?\s*月` | 简写“＜1次/月”或“<1次/月”。 |
| `每月不足1次` | 明确写每月不足 1 次。 |
| `不足1次/月` | 明确写不足 1 次/月。 |
| `＜1次/月` | 明确写＜1次/月。 |

### 经常饮酒（≥1次/月）

| 命中条件 | 大概覆盖范围 |
| --- | --- |
| `经常饮酒` | 明确写经常饮酒。 |
| `常饮酒` | 明确写常饮酒。 |
| `规律饮酒` | 规律饮酒。 |
| `长期饮酒` | 长期饮酒，且未提戒酒。 |
| `每月饮酒` | 每月至少饮酒。 |
| `每周饮酒` | 每周饮酒。 |
| `每日饮酒` | 每日饮酒。 |
| `天天饮酒` | 天天饮酒。 |
| `嗜酒` | 嗜酒。 |
| `酗酒` | 酗酒。 |
| `regex:^(?!.*(?:戒酒|已戒)).*(?:饮酒|喝酒).{0,8}(?:大于等于|不少于|至少|>=|≥)\s*1\s*次\s*/?\s*(?:月|每月)` | 未出现戒酒/已戒时，描述饮酒频率至少每月 1 次。 |
| `regex:^(?!.*(?:戒酒|已戒)).*(?:饮酒|喝酒).{0,8}(?:每月|每周|每日|每天).{0,8}[1-9]\d*\s*次` | 未出现戒酒/已戒时，描述每月、每周、每日或每天饮酒次数。 |
| `regex:^(?!.*(?:戒酒|已戒)).*[1-9]\d*\s*次\s*/?\s*(?:月|周|日|天)` | 未出现戒酒/已戒时，描述“1次/月”“2次/周”等频率。 |
| `regex:^(?!.*(?:戒酒|已戒)).*(?:饮酒|喝酒).{0,12}\d+\s*(?:年|月)` | 未出现戒酒/已戒时，描述饮酒年限或月数。 |

## 不建议自动归类的情况

只写“已戒酒”或“戒酒”，但没有当前饮酒频率，无法判断应归入“从不饮酒”还是保留既往饮酒史。建议先不配置单独的“已戒酒”条件，让系统保持原值或人工确认。
