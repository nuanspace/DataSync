# 吸烟情况字典模板

## 使用位置

接口映射工作台中，选中“吸烟情况”字段后，在“详细设置”中配置：

```text
字典代码：smoking_status
字典匹配：按排序优先命中
```

然后点击“新建字典”或“编辑字典”，按下面顺序配置字典条目。顺序很重要，“按排序优先命中”只取第一条命中的目标选项。

## 推荐目标选项顺序

1. 戒烟<=3月
2. 戒烟>=3月
3. 从不吸烟
4. 偶尔吸烟
5. 仍在吸烟

## 字典条目模板

### 戒烟<=3月

| 命中条件 | 大概覆盖范围 |
| --- | --- |
| `regex:戒烟.{0,8}(?:[1-9]|[1-8]\d|90)\s*(?:天|日)` | 戒烟 1 到 90 天，例如“戒烟30天”“已戒烟 60 日”。 |
| `regex:戒烟.{0,8}(?:1|2|3|一|二|两|三)\s*个?月` | 戒烟 1 到 3 个月，例如“戒烟2个月”“已戒烟三月”。 |
| `戒烟不足3月` | 明确写“戒烟不足3月”。 |
| `戒烟不到3月` | 明确写“戒烟不到3月”。 |
| `戒烟未满3月` | 明确写“戒烟未满3月”。 |
| `戒烟小于3月` | 明确写“戒烟小于3月”。 |
| `戒烟小于等于3月` | 明确写“戒烟小于等于3月”。 |

### 戒烟>=3月

| 命中条件 | 大概覆盖范围 |
| --- | --- |
| `regex:戒烟.{0,8}(?:[4-9]|1[0-2]|四|五|六|七|八|九|十|十一|十二)\s*个?月` | 戒烟 4 到 12 个月，例如“戒烟4个月”“戒烟十月”。 |
| `regex:戒烟.{0,8}(?:半年|[1-9]\d*\s*年|[一二三四五六七八九十]+年|多年)` | 戒烟半年、一年、多年等，例如“戒烟半年”“已戒烟2年”。 |
| `戒烟超过3月` | 明确写“戒烟超过3月”。 |
| `戒烟大于3月` | 明确写“戒烟大于3月”。 |
| `戒烟大于等于3月` | 明确写“戒烟大于等于3月”。 |
| `戒烟≥3月` | 明确写“戒烟≥3月”。 |
| `戒烟>=3月` | 明确写“戒烟>=3月”。 |
| `长期戒烟` | 明确写“长期戒烟”。 |

### 从不吸烟

| 命中条件 | 大概覆盖范围 |
| --- | --- |
| `从不吸烟` | 明确写“从不吸烟”。 |
| `否认吸烟` | 否认当前或既往吸烟。 |
| `否认烟草` | 否认烟草接触。 |
| `无吸烟史` | 明确写无吸烟史。 |
| `无烟史` | 明确写无烟史。 |
| `未吸烟` | 明确写未吸烟。 |
| `平素不吸烟` | 平素不吸烟。 |
| `不吸烟` | 普通“不吸烟”描述。若院内常用“目前不吸烟”表示已戒烟，建议不要配置这一条。 |

### 偶尔吸烟

| 命中条件 | 大概覆盖范围 |
| --- | --- |
| `偶尔吸烟` | 明确写偶尔吸烟。 |
| `偶吸` | 简写“偶吸”。 |
| `偶有吸烟` | 明确写偶有吸烟。 |
| `间断吸烟` | 间断吸烟。 |
| `少量吸烟` | 少量吸烟。 |
| `社交性吸烟` | 社交性吸烟。 |

### 仍在吸烟

| 命中条件 | 大概覆盖范围 |
| --- | --- |
| `仍在吸烟` | 明确写仍在吸烟。 |
| `现吸烟` | 明确写现吸烟。 |
| `目前吸烟` | 明确写目前吸烟。 |
| `仍吸烟` | 明确写仍吸烟。 |
| `继续吸烟` | 明确写继续吸烟。 |
| `长期吸烟` | 长期吸烟，且未提戒烟。 |
| `regex:^(?!.*(?:戒烟|已戒)).*(?:每日|每天|日均).{0,8}\d+\s*支` | 未出现戒烟/已戒时，描述每日多少支，例如“每日10支”。 |
| `regex:^(?!.*(?:戒烟|已戒)).*\d+\s*支\s*/?\s*(?:日|天|每天|每日)` | 未出现戒烟/已戒时，描述“10支/日”“10支每天”。 |
| `regex:^(?!.*(?:戒烟|已戒)).*(?:吸烟|抽烟).{0,12}\d+\s*(?:年|月|支|包)` | 未出现戒烟/已戒时，描述吸烟年限、月数、支数、包数。 |
| `吸烟 && 包` | 同一文本同时包含“吸烟”和“包”。 |
| `抽烟 && 支` | 同一文本同时包含“抽烟”和“支”。 |

## 不建议自动归类的情况

只写“已戒烟”或“戒烟”，但没有时间，无法判断是“戒烟<=3月”还是“戒烟>=3月”。建议先不配置单独的“已戒烟”条件，让系统保持原值或人工确认。

如果业务明确规定“未写戒烟时间默认按戒烟>=3月”，可以把下面条件追加到“戒烟>=3月”：

```text
已戒烟
戒烟
```

## 预期命中示例

| 原始文本 | 预期目标选项 |
| --- | --- |
| 否认吸烟史 | 从不吸烟 |
| 偶尔吸烟 | 偶尔吸烟 |
| 已戒烟2个月 | 戒烟<=3月 |
| 戒烟半年 | 戒烟>=3月 |
| 吸烟20年，每日10支 | 仍在吸烟 |
| 已戒烟，戒烟前每日20支 | 不命中“仍在吸烟”，需要根据是否有戒烟时间进一步判断 |
